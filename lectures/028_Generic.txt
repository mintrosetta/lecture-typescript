Generic Type
    ทำให้เราสามารถนำ class, function, interface มาใช้ซ้ำได้มากขึ้น โดยการเปลี่ยนวิธีการระบุชนิดข้อมูล
    โดยปกติแล้ว เราจะระบุชนิดของข้อมูลลงไปตรง ๆ เช่น 
        function getName(): string {}

    เราสามารถทำให้ยืดหยุ่นมากขึ้นได้ดังนี้
        function getRandomElement<T>(items: T[]): T {}
    จากตัวอย่าง เราได้ใช้ตัวแปร T เข้ามาใส่แทนชนิดข้อมูล
    โดย T จะเป็นตัวแทรของชนิดข้อมูล ซึ่งจะถูกระบุโดยส่วนที่เอาไปเรียกใช้งานว่าต้องประมวลผลกับข้อมูลชนิดอะไร

    เราสามารถเรียกใช้ได้ดังนี้
    let result: number = getRandomElement<number>([1, 2, 3, 4]);

    เราสามารถระบุ Generic Types ได้หลายตัว
    เช่น
        function merg<U, V>(obj1: U, obj2: V): object {
