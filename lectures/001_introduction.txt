Typescript
    เป็น javascript ที่ถูกเพิ่มความสามารถหลาย ๆ ด้าน เช่น ชนิดของข้อมูล 
    เพื่อช่วยให้นักพัฒนาสามารถตรวจจับข้อผิดพลาดได้ตั้งแต่ขั้นตอนการพัฒนา

    โดย typescript ถูกสร้างขั้นโดย microsoft และเป็นโครงการ open-source
    สามารถทำงานได้ทั้งบน browser และ operating system หรือที่ใดก็ตามที่สามารถสั่งให้
    javascript ทำงานได้

    โดยการใช้งานนั้น นักพัฒนาจะเขียนชุดคำสั่งใน typescript และจะทำการ compile ชุดคำสั่ง
    เป็นภาษา javascript และนำ javascript ไปใช้งาน

    โดยสิ่งที่ทำหน้าที่แปรงชุดคำสั่งจาก typescript เป็น javascript นั้นเราจะเรียกว่า typescript compiler

    typescript จะใช้นามสกุลไฟล์เป็น .ts 
    javascript จะใช้นามสกุลไฟล์เป็น .js

    โดยเหตุผลที่เราควรจะใช้ typescript คือ 
        1. มีการรองรับชนิดข้อมูล
        2. จะมีการพัฒนาคุณสมบัติในอนาคตของ javascript หรืออีกชื่อหนึ่งคือ ECMAScript Next หรือ ES Next

    โดยการมาของ typescript ช่วยให้นักพัฒนาสามารถตรวจสอบข้อผิดพลาดของโปรแกรมได้ง่ายขึ้น

    ตัวอย่างเช่น
        เมื่อเรารับข้อมูลมาจาก html input ทุก ๆ ค่าที่เราได้จะเป็น string 
            let input1 = document.getElementById('i1').value;
            let input2 = document.getElementById('i2').value;
        
        เราได้สร้างฟังก์ชันขึ้นมา ซึ่งจะทำหน้าที่ในการบวกเลข
            function add(a, b) {
                return a + b;
            }

        เมื่อผู้ใช้ใส่ค่า input1 = 20, input2 = 10 และส่งเข้าไปที่ฟังก์ชัน add จากที่คาดหวังว่าจะได้ค่า 30 
        เราจะได้ค่า 2010 มาแทน เนื่องจาก input1, input2 เป็น string ทำให้เกิดการนำ string มาเชื่อมต่อกันแทน

        โดย typescript จะเข้ามามีส่วนช่วยในการลดข้อผิดพลาดตรงนี้ได้ โดยการเพื่มชนิดของข้อมูลลงไป
            function add(a: number, b: number) {
                return a + b;
            }
        จากฟังก์ชันดังกล่าว เราจะพบว่าได้มีการเพิ่มชนิดข้อมูลเข้าไปที่ parameter ทั้ง 2 ตัว 
        โดยการบังคับให้ข้อมูลที่รับมาจะต้องเป็นตัวเลขเท่านั้น
