Type Annotations
    เป็นการที่นักพัฒนาเป็นผู้ระบุชนิดของข้อมูลด้วยตัวเองให้กับ variable, functions, objects
    โดยเราสามารถระบุชนิดของข้อมูลได้ด้วยคำสัง : type เช่น let username: string;

    โดนหลังจากที่เราระบุชนิดของข้อมูลแล้ว จะทำตัวตัวแปรดังกล่าว จัดเก็บได้เฉพาะข้อมเป็นที่เป็นชนิดที่กำหนด
    เช่น let age: numbre = 20; จะให้จะเก็บได้เฉพาะข้อมูลที่เป็นตัวเลข ถ้าเราระบุข้อมูลชนิดอื่น ๆ ลงไป
    จะเกิดข้อผิดพลาด เช่น let age: number = "Hello World"; // compile error

    โดยชนิดข้อมูลทั้งหมดมีดังนี้
        1. number       จัดเก็บข้อมูลที่เป็นตัวเลข โดยได้ทั้งเลขจำนวนเต็มและทศนิยม
        2. string       จัดเก็บข้อมูลที่เป็นตัวอักษร โดยสนุบสนุนทั้ง sigle-quotes('), double-quotes(") และ backtick(`)
        3. boolean      จัดเก็บข้อมูลจริงหรือเท็จ (true or false)
                            3.1 โดยเราจะมี boolean operator (ตัวดำเนินการ) ดังนี้
                                3.1.1   && (and, และ) ถ้าตัวถูกดำเนินการทั้ง 2 เป็นจริง จะส่งคืน true, นอกนั้น false เช่น a && b
                                3.1.2   || (or, หรือ) ถ้าตัวถูกดำเนินการตัวใดตัวหนึงเป็นจริงจะส่งคืน true นอกนั้น false เช่น a || b 
                                3.1.3   ! (not) กลับค่าจากจริงเป็นเท็จ และเท็ตเป็นจริง เช่น a = true; a = !a; a จะมีค่าเป็น false
        4. array        จัดเก็บข้อมูลทีละหลายค่า เช่น number[] หมายถึง จัดเก็บรายการของข้อมูลที่เป็นตัวเลข
        5. objects      กลุ่มของข้อมูลที่จัดอยู่ในกลุ่มเดียวกัน โดยจะจัดเก็บในรูปแบบ key - value หรือ จัดเก็บได้ทุกข้อมูลที่ไม่ใช่ primitive type
                            5.1 โดยเราสามารถระบุชนิดของข้อมูลภายใน object ได้ดังนี้
                                let person: {
                                    name: string,
                                    age: number
                                }
                                person = {
                                    name: "bike",
                                    age: 23
                                }
                                โดยจากชุดคำสั่งข้างบน จะบังคับให้ person รับแค่ object ที่มี properties 2 ตัว คือ name, age
        6. function     จัดเก็บฟังก์ชันภายในตัวแปร
                            6.1 เราสามารถระบุข้อมูลของฟังก์ชันที่จะจัดเก็บได้ดังนี้ let functionName: (params) => return_val
                                เช่น let greeting: (name: string) => string;
                                โดยจากคำสั่งดังกล่าว จะทำให้ตัวแปร greeting รับเฉพาะฟังก์ชันที่รับ parameter เป็น string 1 ตัว 
                                และส่งคืนข้อมูลเป็น string
        7. bigint       จัดเก็บข้อมูลตัวเลขที่มีขนาดใหญ่ได้
        8. tuple        จัดเก็บข้อมูลเหมือนกับ array แต่มีความแต่งต่างกันดังนี้
                            8.1 แต่มีความแต่งต่างกันดังนี้
                                8.1.1 การเก็บข้อมูลของ tuple จะตายตัว 
                                8.2.2 ชนิดของข้อมูลภายใน tuple จะต้องถูกระบุไว้ร่างหน้า โดยสามารถไม่เหมือนกันได้ ตัวอย่างเช่น
                                    8.2.1.1 let skill: [string, number] = ["Programming", 5];
                                8.3.3 ลำดับข้อมูลของ tuple ไม่สามารถสลับกันได้ เช่น ระบุ [string, number] แต่ขั้นตอนการ assign เราใส่ [4, "Hello"] 
                                    จะเกิดข้อผิดพลาด error TS2322: Type 'string' is not assignable to type 'number'.
                            8.2 optional tuple element สามารถกำหนดให้ข้อมูลของ tuple ไม่จำเป็นต้องใส่ได้ เช่น [number, number, number, number?] 
                                จะได้ตัวอย่างข้อมูลดังนี้ [0, 255, 255, 0.5]
        9. enum         จัดเก็บข้อมูล ที่ระบุคำตอบที่ถูกต้องไว้กับข้อมูลอยู่แล้ว
                            9.1 มันย่อมาจาก enumerated
                            9.2 มักใช้กับข้อมูลที่เราจะต้องระบุได้อย่างชัดเจน และไม่สามารถเป็นอย่างอื่นได้
                            9.3 ข้อมูลที่ได้จาก enum จะส่งคืนมาเป็น index ของข้อมูล
                            9.4 เราสามารถกำหนด index ให้กับข้อมูลใน enum ได้
        10. unknow      จัดเก็บข้อมูลที่เราไม่รู้ว่ามันจะเป็นชนิดข้อมูลอะไร 
                            10.1 แตกต่างจาก any โดยจะมีความปลอดภัยในการใช้งานมากกว่า เนื่องจากจะไม่สามารถทำงานต่อได้
                                 ถ้านักพัฒนายังไม่เปลี่ยนเป็นชนิดข้อมูลที่ชัดเจน หรือใช้ type assertion
                            10.2 มีการบังคับให้ตรวจสอบชนิดข้อมูลก่อนการทำงาน
                            10.3 มักใช้สำหรับการรองรับข้อมูลที่มาจากแหล่งอื่น ๆ เช่น API call เนื่องจา่กเรายังไม่รู้ว่า
                                 API จะส่งข้อมูลอะไรมาบ้าง แล้วนำมาแปรงทีหลัง
                                10.3.1 ตัวอย่างการแปรงข้อมูล
                                    const posts: unknow = await fetct(url);
                                    (posts as {userId: number, id: number, title: string}[]).map()

    Primitive data type
        เป็นชนิดข้อมูลดั้งเดิมของภาษา โดยจะมีดังนี้
            1. number 
            2. bigint 
            3. string
            4. boolean
            5. null 
            6. undefined
            7. symbol
