Generic Constraints
    เราสามารถระบุได้ว่า generic type ดังกล่าว จะต้องมีการสืบทอดคุณสมบัติอะไรมา
    เช่น 
        function merge<U extends object, V extends object>(obj1: U, obj2: V) {

        }

    ถ้าหากมีการใส่ข้อมูลที่ไม่ได้มีการ extends object จะเกิดข้อผิดพลาด
    let person = merge(
        { name: 'John' },
        25
    );
    เกิดข้อผิดพลาด Argument of type '25' is not assignable to parameter of type 'object'.
