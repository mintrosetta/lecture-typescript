Typescript For
    เป็นชุดคำสั่งที่ใช้ในการทำซ้ำกลุ่มของชุดคำสั่งด้านใน โดยจะทำตามซ้ำตราบใดที่เงื่อนไขเป็นจริง

    รูปแบบชุดคำสั่ง
        for (initialization; condition; expression) {
            statement
        }

    โดยแต่ละส่วนจะอธิบายได้ดังนี้
        1. initialization   ใช้สำหรับตั้งข้อมูลเริ่มต้นก่อนการวนซ้ำ
        2. condition        ใช้สำหรับเขียนชุดคำสั่งเงื่อนไขที่จะทำให้หยุดการวนซ้ำ
        3. expression       ใช้สำหรับเขียนชุดคำสั่งที่จะต้องทำงานก่อนจะกลับไปตรวจสอบ condition

    ตัวอย่างชุดคำสั่ง 
        for (let i: number = 0; i < 10; i++) {
            console.log(i);
        }
