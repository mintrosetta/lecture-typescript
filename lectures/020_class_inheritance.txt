Typescript Inheritance
    เป็นการสืบทอดคุณสมบัติและพฤติกรรม จากคลาสหนึ่งไปยังอีกคลาสหนึ่ง
    โดยคลาสที่เป็นผู้สืบทอดจะถูกเรียกว่า parent class 
    และคลาสที่สอบทอดความสามารถไปเราจะเรียกว่า child class

    โดยการสืบทอดความสามารถใน typescript เราจะใช้ keyword extends
    ตัวอย่างเช่น
        class Employee extends Person {

        }

    super keyword
        เป็นการเรียกใช้งานคุณสมบัติหรือพฤติกรรมของคลาสแม่ และเราสามารถเรียกใช้งาน constructor ของ
        คลาสแม่ได้ด้วย 
        ตัวอย่าง  
            class Employee extends Person {
                constructor () {
                    super();
                }
            }

    ทำไมต้องเรียกใช้ constructor ของ parent ?
        เนื่องจากในบางครั้ง จะมีการตั้งค่าคุณสมบัตต่าง ๆ ของคลาสแม่ ที่คลาสลูกต้องการจะใช้ด้วย
        ทำให้เราจำเป็นต้องส่งบางอย่างไปให้กับคลาสแม่ใช้งาน

    method overriding
        เป็นการเขียนทับฟังก์ชันของคลาสแม่ บนคลาสลูก เพื่อเขียนวิธีการทำงานใหม่บนพฤติกรรมเดิม
